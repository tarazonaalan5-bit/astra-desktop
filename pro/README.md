# ASTRA Desktop Pro

Aplicación desktop profesional para ASTRA con:
- Chat en tiempo real
- Navegador embebido
- Panel de IA
- Historial de conversaciones
- Interfaz moderna y responsive

## Instalación

```bash
cd pro
npm install
```

## Desarrollo

```bash
npm run dev
```

Abrir: `http://localhost:5173`

## Build

```bash
npm run build
```

## Requisitos de Backend

Esta aplicación espera que el backend ASTRA esté corriendo en:

```
ws://localhost:8000/ws/<room>
```

## Características

✅ Login con usuario  
✅ Chat en tiempo real con WebSocket  
✅ Navegador embebido  
✅ Panel de IA para tareas  
✅ Historial de conversaciones  
✅ Interfaz oscura profesional  
✅ Responsive y moderna  

## Desarrollo

La aplicación está lista para ser empaquetada con Electron o Tauri para crear un ejecutable de escritorio.
